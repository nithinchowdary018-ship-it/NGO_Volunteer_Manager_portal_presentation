# ImpactPulse - NGO Volunteer Management Portal

**ImpactPulse** is a responsive, feature-rich web application designed to streamline NGO operations, volunteer coordination, and impact tracking. Built with modern web technologies, it bridges the gap between passionate volunteers and community organizations by offering seamless shift scheduling, hours verification, and real-time impact analytics.

---

## 🌟 Key Features

### 1. 🤝 Volunteer Portal & Opportunities Board
* **Explore Opportunities:** Filter active community drives by **Cause** (*Education*, *Environment*, *Food Security*, *Healthcare*) and **Commitment Type** (*One-time*, *Weekly*, *Flexible*).
* **Live Search:** Instantly find events by title, location, or keywords.
* **Instant Sign-Up:** Secure shift enrollment with real-time slot tracking and instant updates.
* **Self-Logging:** Easily log past volunteer hours for external or unlisted community work, pending coordinator verification.

### 2. 📋 Coordinator & Director Administration
* **Role-Based Views:** Switch seamlessly between **Volunteer**, **Coordinator**, and **NGO Director** views to test administrative workflows.
* **Event Creation:** Publish new volunteering programs with customizable slots, dates, and locations.
* **Approval Workflow:** Review pending volunteer registrations and service hour claims with single-click approval or rejection.
* **Moderation:** Remove outdated or completed events directly from the board.

### 3. 📊 Impact Analytics & Gamification
* **Service Metrics:** Monitor total active volunteers, verified service hours, and estimated economic impact value ($23/hr national benchmark).
* **Interactive Charts:** Powered by **Chart.js** to visualize monthly hours contribution and cause-based distribution.
* **Badges & Recognition:** Track personal milestones (e.g., *Silver Hero*) and preview verified certificate generation.

---

## 🛠️ Technology Stack

* **HTML5 / CSS3:** Semantic layout with modern responsive design principles.
* **Tailwind CSS (CDN):** Utility-first styling with a custom emerald/brand color palette and smooth transitions.
* **JavaScript (Vanilla ES6+):** Dynamic DOM manipulation, reactive state management, and event handling.
* **FontAwesome (v6.4.0):** Clean vector iconography for UI enhancements.
* **Chart.js:** Interactive data visualizations for the analytics dashboard.

## 🚀 Getting Started

Since **ImpactPulse** is built as a single-file client-side web application using CDN-hosted libraries, no complex build steps, backend servers, or package managers (`npm`, `pip`) are required to run it.

### Prerequisites
Any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).

### Installation & Running Locally
1. Clone or download the repository to your local machine.
2. Save the main application file as `index.html`.
3. Double-click `index.html` or open it directly in your preferred web browser.

---

## 🧭 How to Use

1. **Browse & Enroll:** Use the **Opportunities** tab to view open drives. Click **Sign Up** to join a shift.
2. **Track Your Hours:** Switch to the **My Shifts & Hours** tab to view your status, check your badge tier, or use **Self-Log Past Hours** to submit new entries.
3. **Test Admin Controls:** 
   * Locate the **Role Selector** dropdown in the top navigation bar and switch from *Volunteer View* to **Coordinator View** or **NGO Director View**.
   * Access the **Volunteer Approvals** tab to approve or reject pending hours submissions.
   * Use the **Create New Event** button on the Opportunities banner to publish new drives.
4. **Analyze Impact:** Click on **Impact Analytics** to review organizational charts and service metrics.
